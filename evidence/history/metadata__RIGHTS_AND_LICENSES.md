# Droits et licences — propositions à confirmer

Les licences ci-dessous sont des **propositions**. Ce fichier n'accorde aucune licence tant que le détenteur des droits ne les a pas confirmées explicitement.

- Manuscrit, README, registres, métadonnées et données tabulaires : Creative Commons Attribution 4.0 International (`CC BY 4.0`) proposée.
- Code original et code de réanalyse : licence MIT proposée.
- Figures : `CC BY 4.0` proposée si l'auteur détient les droits sur tous les éléments graphiques.
- Documents tiers ou citations : conserver leurs conditions propres; ne pas relicencier le texte de tiers.

Avant dépôt, le propriétaire doit :

1. confirmer qu'il est titulaire ou autorisé pour chaque fichier;
2. vérifier les contributions de logiciels ou textes produits par des tiers;
3. ajouter les fichiers de licence effectifs souhaités;
4. compléter le nom du créateur et les attributions;
5. retirer tout fichier dont les droits ne peuvent pas être établis.
