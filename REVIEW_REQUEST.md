# Demande de relecture scientifique indépendante

## Statut

Aucune revue scientifique humaine extérieure n’est actuellement attestée. Les rapports Codex/ChatGPT présents dans le dossier sont des contrelectures assistées par IA et ne doivent pas être cités comme une évaluation par les pairs.

## Relecture sollicitée

Une relecture humaine indépendante est demandée, en priorité sur les points suivants :

1. formulation exacte du modèle de réseau randomisé et mesure de probabilité employée ;
2. passage du modèle local parabolique au cadre global ;
3. statut des deux termes proposés, des constantes candidates et du reste asymptotique ;
4. méthodologie statistique, hypothèse de covariance diagonale et indépendance du jeu confirmatoire ;
5. portée finie de l’audit géométrique et traitement des formes singulières ;
6. incidence scientifique des données ou traces absentes recensées dans `evidence/LIMITS_AND_MISSING.md`.

## Réponse souhaitée

Merci d’indiquer précisément les fichiers, sections, équations ou données examinés, puis de distinguer :

- les affirmations vérifiées dans le périmètre examiné ;
- les erreurs ou ambiguïtés reproductibles ;
- les hypothèses supplémentaires nécessaires ;
- les expériences, preuves ou données complémentaires recommandées.

Les retours peuvent être soumis sous forme d’issue GitHub. Une absence d’objection ne sera pas interprétée comme une validation.
