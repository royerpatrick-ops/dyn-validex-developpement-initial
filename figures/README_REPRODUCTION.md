# Figures et reproduction

Les PNG de ce dossier sont des figures historiques sélectionnées. Leur présence documente l'état du projet; elle ne remplace pas les CSV sources.

- `C_eff_v10.png` : constante effective et comparaison au modèle historique.
- `shape_universality.png` : comparaison de formes.
- `sliding_window_gamma.png` : exploration de l'exposant local.
- `superellipse_gamma.png` : exploration des superellipses.
- `superellipse_p1.75_singuliere.png` : cas singulier p=1.75 associé au JSON brut.
- `superellipse_p1.5_singuliere.png` : figure historique sans JSON brut associé.

Les quatre premières figures sont reproduites par les scripts homonymes ou par les scripts d'analyse présents sous `code/original/`, depuis les CSV historiques. La figure p=1.75 est associée à `code/reanalysis/recompute_superellipse_stats.py` pour les statistiques, mais sa mise en page originale dépend du script `test_superellipse_singuliere.py`. La figure p=1.5 doit être considérée comme documentaire tant que le JSON brut manque.

Le manuscrit révisé privilégie les tableaux de résultats recalculés et n'utilise aucune figure comme preuve autonome.
